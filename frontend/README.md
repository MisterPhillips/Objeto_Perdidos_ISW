# Objetos Perdidos

Frontend desarrollado con React, Vite y Tailwind CSS 4.

## Desarrollo

Desde esta carpeta, ejecuta `npm install` para instalar las dependencias y `npm run dev` para iniciar el servidor local.

## Comprobaciones

- `npm run build`: genera la versión de producción.
- `npm run lint`: comprueba el código con ESLint.
